## Database Queries

### DO Dispatch History Query
```sql
SELECT 
    ds.*,
    do.DO_Name,
    do.CNIC,
    COUNT(dsi.itemID) as itemCount
FROM do_sales ds
INNER JOIN distributing_officer do ON ds.DO_ID = do.DO_ID
LEFT JOIN do_sale_items dsi ON ds.saleID = dsi.saleID
GROUP BY ds.saleID
ORDER BY ds.saleDate DESC, ds.createdAt DESC
```

### DO Pending Query
```sql
SELECT 
    ds.*,
    do.DO_Name,
    DATEDIFF(ds.dueDate, CURDATE()) as daysRemaining,
    CASE 
        WHEN ds.dueDate IS NULL THEN 'no_due'
        WHEN DATEDIFF(ds.dueDate, CURDATE()) < 0 THEN 'overdue'
        WHEN DATEDIFF(ds.dueDate, CURDATE()) <= 7 THEN 'urgent'
        ELSE 'normal'
    END as urgencyStatus
FROM do_sales ds
WHERE ds.paymentStatus IN ('pending', 'partial')
ORDER BY urgencyStatus, ds.dueDate ASC
```

### Overdue Count Query
```sql
SELECT COUNT(*) as overdueCount
FROM do_sales
WHERE paymentStatus IN ('pending', 'partial')
AND dueDate IS NOT NULL
AND DATEDIFF(dueDate, CURDATE()) < 0
```
